👺 ClipGoblin

Turns a long stream VOD into short vertical clips with hooks, big captions and jump cuts, and can post them to YouTube Shorts, TikTok and Instagram Reels.

Download ClipGoblin (Mac, 0.4 MB)

Start it

  1. Install Node.js (the LTS version).
  2. Unzip the download and double-click Start ClipGoblin.command. The first time, macOS asks: right-click it → Open → Open.
  3. The first start installs everything (a few minutes). Then ClipGoblin opens in your browser at localhost:4777.

Make it smart

It works without any keys, but for the best clips put an Anthropic API key in Settings (from console.anthropic.com; usage is billed to your own account).

Auto-posting

Settings → Connections walks you through connecting your own YouTube, TikTok and Instagram accounts. New YouTube and TikTok apps only post privately until those platforms approve them. Instagram needs a Business or Creator account.
